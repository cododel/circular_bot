# circle-overlay-bot

Telegram бот для обработки Video Notes (кружочков) и обычных видео — накладывает кастомный оверлей вместо дефолтного белого фона Telegram.

## Что делает бот

1. Пользователь отправляет кружок (video note), обычное видео или видео файлом
2. Бот предлагает выбрать источник подписи (автор/отправитель/кастомный текст)
3. Предлагает выбрать формат (9:16, 1:1, 16:9, 4:5)
4. Обрабатывает видео с прогрессом каждые 3 секунды:
   - Создаёт ambient background в стиле YouTube
   - Маскирует кадр в круг по центру
   - Добавляет текстовый оверлей
5. Отправляет готовое видео

### Ambient background

Фон строится не одним усреднённым цветом, а по схеме YouTube: кадр
уменьшается до маленькой цветовой карты (~96px), сглаживается во времени,
сильно размывается, слегка досыщается и растягивается обратно на весь холст.
Маленькая карта сохраняет расположение цветов — свет слева остаётся слева, —
а среднее по кадру превратилось бы в серо-коричневое пятно.

Временное сглаживание — экспоненциальное скользящее среднее по последним
кадрам (`tmix` с растущими весами). Без него фон дёргается на каждом резком
движении.

### Кружки и обычные видео

Пути разведены, потому что источники разные:

- **Кружок (video note)** — Telegram запекает в файл свою белую круглую маску,
  так что за пределами вписанного круга в кадре нет ничего, кроме белого.
  Ambient и подложка берутся только из вписанного в круг квадрата, а сам
  видимый круг слегка зумится, чтобы срезать сглаженную кайму маски. Подложка
  за кружком тоже круглая — квадратная рисовала бы ровно тот силуэт, который
  мы убираем.
- **Обычное видео** — берётся центральный квадрат кадра, весь кадр целиком
  идёт в ambient.

Размер входящего файла ограничен лимитом Bot API (20 МБ, настраивается через
`MAX_VIDEO_SIZE_MB`).

## Быстрый старт

```bash
# Клонирование
git clone git@github.com:cododel/circular_bot.git
cd circular_bot

# Настройка
cp .env.example .env
# Отредактируй .env, добавь BOT_TOKEN от @BotFather

# Запуск
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m bot
```
